# AI Transform v1 — Final Implementation Document
Last updated: 2025-11-05 23:30:14

## 0) Executive Summary
Goal: Add a separate **AI Transform** tab that lets users describe table edits in plain English. The app prompts an LLM, shows generated Pandas code, dry-runs on a sample, presents a diff, and then applies changes to the working DataFrame with undo support. Scope is **basic, safe table edits** only.

## 1) Scope and Non‑Goals
**In scope v1**
- One in-memory DataFrame (`st.session_state.df`).
- Ops: filter, sort, select, rename, computed columns, type casts, dedupe, fill/clip, string/date ops, groupby/aggregate, pivot/unpivot.
- Generated code contract: `def transform(df): return df_out` (pure, no global state).

**Out of scope v1**
- Joins/merges across files, file I/O, network calls, plotting, long-running transformations, UDFs that touch the OS, any subprocess.

## 2) UI/UX Specification
**Placement**: New tab: `Pivot | Charts | AI Transform`  
**Flow**: Prompt → Code → Dry‑run → Diff → Apply/Undo

**Sections**
1. **Context Card**
   - File/DataFrame selector (if you later support multiple), else a read-only schema: columns, dtypes, nrows, null rates.
   - Toggle to show N sample rows.
2. **Model & Settings**
   - Vendor select: `["OpenAI", "Local"]` (more later).
   - Model select depends on vendor.
   - Temperature slider, optional token budget indicator.
   - Banner warning: “Cloud model may send data to vendor” when applicable.
3. **Prompt Composer**
   - Multiline box with examples and quick-insert chips for column names.
   - Buttons: **Generate**, **Explain**, **Reset**.
4. **Code Preview**
   - Read-only block with copy button.
   - Sanitizer warnings if code contains blocked patterns.
5. **Dry‑run Preview**
   - Runs `transform(df_sample)` on a small sample (default 2% or 10k rows cap).
   - Shows preview table and **Diff Summary**:
     - Row count Δ
     - Columns added/removed/renamed
     - Dtype changes
     - New columns sample values (head)
6. **Apply / Undo**
   - **Apply** replaces `st.session_state.df` with result.
   - **Undo last** reverts to immediately prior snapshot.
   - **Transform Log** table listing timestamp, prompt, code hash, rows/cols Δ.

7. **Export**
   - Export Transform Log as `.json` and `.py` chained recipe.

## 3) Contracts and Data Structures
**Function contract** generated by LLM:
```python
def transform(df):
    # must return a new DataFrame named result or return directly
    return df_out
```
**Session state**
- `df`: current working DataFrame
- `ai_code`: latest generated code string
- `ai_preview_df`: last dry-run result
- `transform_log`: list[TransformStep]

**TransformStep (JSON-serializable)**
```json
{
  "id": "<uuid4>",
  "ts": "<iso8601>",
  "prompt": "...",
  "code_hash": "sha256:...",
  "schema_before": {"columns": [...], "dtypes": {} , "nrows": 12345},
  "schema_after": {"columns": [...], "dtypes": {} , "nrows": 12001},
  "diff": {"rows_delta": -344, "cols_added": ["Margin"], "cols_removed": [], "renamed": {}, "dtype_changes": {}}
}
```

## 4) Module Design
```
/app.py                         # Streamlit tabs + wiring
/core.py                        # Shared helpers (add schema_snapshot())
/llm_orchestrator.py            # Prompt build, provider call, contract enforcement
/code_sanitizer.py              # AST allow-list + static checks
/sandbox_executor.py            # Restricted exec of transform()
/diff_tools.py                  # Schema/shape diffs
/transform_log.py               # Append, export, undo
/providers/
  __init__.py
  openai_provider.py            # LangChain/OpenAI wrapper
  local_provider.py             # Ollama/vLLM wrapper (optional placeholder)
```

### 4.1 llm_orchestrator.py
- `generate_code(prompt: str, schema: dict, vendor: str, model: str, temperature: float) -> str`
- Steps:
  1) Build system, context, and user messages.
  2) Call selected provider.
  3) Extract code block text only.
  4) Verify code contains exactly one `def transform(df):`.
- Prompt rules: state bans, list allowed ops, include schema and value hints.

### 4.2 code_sanitizer.py
- `validate(code: str) -> list[str]` returns a list of violations; empty if safe.
- `ast.parse` then walk nodes; allow-list Pandas/Numpy, Python arithmetic, indexing, masks, groupby agg, assign, rename.
- Block: imports, file/network, dunder magic, `eval/exec/compile`, attribute escapes.

### 4.3 sandbox_executor.py
- `dry_run(code, df, sample_frac=0.02, max_rows=10000) -> (preview_df, diff)`
- `apply(code, df) -> (df_out, diff)`
- Create a new module namespace with restricted globals: `{"pd": pandas, "np": numpy}`
- Timeout via `multiprocessing` worker with a hard kill.
- Memory guard by sampling on dry-run and checking output shape before returning.

### 4.4 diff_tools.py
- `schema_snapshot(df) -> dict`
- `compute_diff(df_before, df_after) -> dict` with rows/cols deltas, dtypes changes, renames heuristic.

### 4.5 transform_log.py
- `append(step_prompt, code, diff, schema_before, schema_after) -> None`
- `undo_last() -> df_prev`
- `export_recipe_py(steps) -> str`
- `export_manifest_json(steps) -> str`

## 5) Streamlit Wiring (high level)
```python
tab_pivot, tab_charts, tab_ai = st.tabs(["Pivot", "Charts", "AI Transform"])

with tab_ai:
    schema = schema_snapshot(st.session_state.df)
    vendor = st.selectbox("LLM Vendor", available_vendors())
    model = st.selectbox("Model", models_for(vendor))
    temp = st.slider("Temperature", 0.0, 1.0, 0.2, 0.05)
    prompt = st.text_area("Describe your edit", height=140)

    if st.button("Generate"):
        code = orchestrator.generate_code(prompt, schema, vendor, model, temp)
        violations = sanitizer.validate(code)
        if violations:
            st.error("\n".join(violations))
        else:
            st.session_state.ai_code = code
            st.code(code, language="python")

    if "ai_code" in st.session_state and st.button("Dry-run on sample"):
        prev_df, diff = executor.dry_run(st.session_state.ai_code, st.session_state.df)
        st.dataframe(prev_df, use_container_width=True)
        render_diff(diff)

    if "ai_code" in st.session_state and st.button("Apply to working DataFrame"):
        before = st.session_state.df
        after, diff = executor.apply(st.session_state.ai_code, before)
        st.session_state.df = after
        transform_log.append(prompt, st.session_state.ai_code, diff, schema_snapshot(before), schema_snapshot(after))

    if st.button("Undo last"):
        st.session_state.df = transform_log.undo_last()
```

## 6) Prompt Template (core idea)
**System**: “You write safe, deterministic Pandas code that edits a single DataFrame named `df`. Use only `df`, `pd`, `np`. No imports, no file or network I/O, no plotting, no OS access. Return a single function `def transform(df): ...` and nothing else.”  
**Context**: columns, dtypes, null rates, select example values.  
**User**: natural instruction.  
**Output**: code only.

## 7) Security Model
- Static checks: AST allow-list, block risky nodes/names.
- Runtime sandbox: restricted globals, separate process with timeout.
- Data handling: redact obvious identifiers in prompt context; red banner if a cloud model is selected.
- Logging: prompts/code kept in memory only unless user exports.
